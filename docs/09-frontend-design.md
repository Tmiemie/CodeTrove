# CodeTrove 前端视觉与交互规范

## 1. 设计定位

CodeTrove 前端采用 **蓝紫粉仪表盘 80% + 猫咪策展员品牌 20%**。整体结构参考用户确认的界面方向：浅蓝页面底色、深蓝固定侧栏、白色悬浮内容卡、紫粉渐变作为主要操作和激活状态。

界面首先是高信息密度、可信赖的代码协作工具；猫咪元素只负责品牌识别、空状态和关键成功反馈，不干扰 Diff、测试报告、设置表单等工程信息。

## 2. 布局结构

- **桌面端**：左侧 220～264px 深蓝固定侧栏，右侧为顶栏、仓库标题、业务内容和页脚。
- **侧栏**：品牌、当前仓库、分组导航、质量守门提示和个人资料。
- **顶栏**：当前页面上下文、全局搜索、创建入口和通知。
- **内容区**：浅蓝背景，核心模块使用白色悬浮卡片和柔和阴影。
- **移动端**：侧栏变为抽屉，顶栏保留菜单、页面名、搜索和通知。

## 3. 主题世界

- **世界**：一座由代码仓库、评审记录和测试证据组成的数字藏馆，一只猫咪策展员守护主分支。
- **材质**：深蓝控制台、浅蓝工作台、白色资料卡、紫粉数字印章、细腻悬浮阴影。
- **核心气质**：清爽、专业、亲和、轻盈、具有个人辨识度。
- **签名元素**：带猫耳的代码收藏盒标识；只用于品牌、空状态和关键成功状态。

## 4. 色彩 Token

| Token | 建议值 | 用途 |
| --- | --- | --- |
| Canvas | `#EDF4FF` | 浅蓝页面背景 |
| Surface | `#FFFFFF` | 内容卡片 |
| Sidebar | `#152047` | 深蓝侧栏 |
| Ink | `#172550` | 标题和主要文字 |
| Muted ink | `#69779D` | 次要说明 |
| Border | `#DFE7F7` | 卡片和表单描边 |
| Purple | `#665CE8` | 主要操作起始色 |
| Pink | `#E5489C` | 渐变强调色 |
| Gradient | `#665CE8 → #E5489C` | 主操作、侧栏激活、品牌标识 |
| Success | `#29B86F` | 成功与通过状态 |
| Danger | `#EA5C7A` | 失败和危险操作 |

代码 Diff 的新增、删除颜色继续遵循开发者熟悉的绿色和红色语义，不使用紫粉渐变覆盖代码语义。

## 5. 组件规则

### 品牌与头像

- 左上角品牌使用“猫耳 + 代码收藏盒”简洁线性标识，并放入紫粉渐变方形容器。
- 用户头像可使用极简猫脸轮廓，但保持小尺寸可识别。
- Footer 复用同一品牌标识，不出现第二套吉祥物。

### 侧栏导航

- 导航按 Repository、Quality 等业务分组。
- 激活项使用紫粉渐变背景、白色文字和轻阴影。
- 非激活项使用低对比蓝灰色，hover 时轻微右移。
- Pull Request 等数量使用侧栏小徽标。

### 卡片与按钮

- 内容卡片使用 13～15px 圆角、浅边框和柔和蓝色阴影。
- 常规按钮使用白底；主操作使用紫粉渐变。
- 成功与危险操作仍保留绿、红业务语义。
- 禁止在同一区域堆叠多个渐变按钮。

### 猫爪元素

猫爪只用于：

- 空结果或空列表提示。
- Check 全部通过、合并成功等关键状态。
- 极少量辅助提示。

猫爪不得用于代码 Diff、错误状态、安全警告、每一行列表或每个按钮。

## 6. 页面要求

- **仓库页**：文件列表和 README 保持工程密度；右侧信息区改为独立白色卡片。
- **Pull Request 列表**：筛选工具和列表组成完整卡片，空状态使用猫爪。
- **Pull Request 详情**：Tab 使用白色卡片承载，评论、Check 和 Merge 区分明确。
- **Actions**：工作流摘要、Job 导航和测试详情保持标准状态色。
- **Settings**：表单和分支保护卡片使用浅蓝输入背景，危险区保持红色。

## 7. 动效与可访问性

- 只允许简短 hover、抽屉、toast 和成功反馈动效。
- 猫耳或猫尾不持续摆动。
- 支持 `prefers-reduced-motion`。
- 颜色之外必须同时使用图标和文字表达状态。
- 键盘焦点清晰，文本对比度满足后台工具阅读要求。

## 8. 验收标准

- 第一眼呈现浅蓝、深蓝、紫粉渐变的现代仪表盘风格。
- 桌面端固定侧栏与内容卡片层级清晰；移动端侧栏可收起。
- 猫咪元素能形成品牌记忆，但不降低专业性。
- 仓库、Diff、Check、测试报告的信息层级不被装饰干扰。
- 生产构建和浏览器首页渲染检查通过。
