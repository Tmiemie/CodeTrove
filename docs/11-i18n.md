# CodeTrove 中英文双语规范

## 1. 功能目标

CodeTrove 前端和项目入口文档提供完整的英文、简体中文双版本。英文继续作为默认语言，用户可在界面中随时切换，切换后当前页面、导航、按钮、提示、空状态和业务说明立即更新，不刷新或丢失当前操作状态。

## 2. 支持范围

必须双语化：

- 全局侧栏、顶栏、搜索框、仓库标题区和页脚。
- 仓库页、Pull Request 列表与详情、Actions、Settings。
- 按钮、Tab、表单标签、筛选项、状态说明、Toast、空状态和错误提示。
- 前端演示数据中的自然语言标题、提交说明、评论、评审意见和 README 展示正文。
- 页面文档标题、无障碍 `aria-label` 和必要的辅助文本。

保持原文、不翻译：

- 代码、文件路径、类名、方法名和 JSON Pointer。
- Git 分支名、commit hash、仓库 slug 和用户名。
- 测试用例 `case_key`、错误码、API 路径和技术产品名称。
- 用户实际输入或后端返回且未声明为可本地化的内容。

## 3. 默认语言与持久化

- 默认语言：英文 `en-US`。
- 支持语言：英文 `en-US`、简体中文 `zh-CN`。
- 用户主动切换后，将语言写入浏览器 `localStorage`，键名统一为 `codetrove.locale`。
- 重新打开页面时优先读取已保存语言；没有保存值时使用英文。
- 首版不根据浏览器语言自动覆盖默认语言，避免同一演示环境出现不确定界面。
- 切换语言不得改变路由、筛选条件、未提交评论、合并状态等页面状态。

## 4. 切换入口

- 桌面端：放在全局顶栏右侧、通知按钮之前或旁边。
- 移动端：顶栏保留同一入口，保证无需打开侧栏即可切换。
- 控件使用地球图标加短标签：英文界面显示“中文”，中文界面显示“EN”。
- 按钮必须包含随当前语言变化的 `aria-label`，不能只依赖图标表达功能。
- 切换完成后显示短暂 Toast，例如“已切换为中文”或“Switched to English”。

## 5. 技术实现约束

- Vue 3 前端采用集中式本地化资源，不允许在页面组件中散落语言判断。
- 消息键按领域组织，例如 `common.*`、`navigation.*`、`repository.*`、`pullRequest.*`、`actions.*`、`settings.*`。
- 带变量的句子使用参数插值，不拼接不完整句子。
- 数量、日期和相对时间通过 locale 格式化；演示数据不得把完整英文时间字符串写死在组件中。
- 缺失翻译必须在开发或构建检查阶段暴露，不得静默显示空白。
- 后端错误码保持稳定，前端按错误码映射用户可见双语信息；不可识别错误使用统一兜底文案。

## 6. README 双版本

- `README.md`：英文主 README。
- `README.zh-CN.md`：内容对应的简体中文 README。
- 两份 README 顶部互相链接：`English | 简体中文`。
- 两份文档保持相同章节、命令、路径、端口和环境变量名。
- 命令行、代码块、环境变量和 URL 不翻译，只翻译说明文字。
- 任一版本发生结构性变更时，必须同步更新另一版本。

## 7. 与视觉规范的关系

- 语言按钮沿用蓝紫粉仪表盘主题，不新增第三套强调色。
- 中文字体使用系统中文无衬线字体回退，英文继续使用现有系统字体栈。
- 中文文本通常更短但字形更密，应检查侧栏、按钮、表单和状态徽标是否仍有合理间距。
- 英文长文案必须允许弹性布局或换行，不通过缩小到不可读字号解决溢出。
- 猫咪品牌元素、图标和业务状态语义不因语言改变。

## 8. 验收标准

- [x] 首次打开默认显示英文。
- [x] 顶栏语言按钮在桌面端和移动端均可访问。
- [x] 切换中文后所有产品自有可见文案均更新，技术标识保持不变。
- [x] 刷新页面后保持用户上次选择的语言。
- [x] 切换语言不改变当前路由和本地交互状态。
- [x] 两种语言下均无明显截断、溢出、按钮变形或布局跳动。
- [x] `README.md` 和 `README.zh-CN.md` 章节与命令一致，并提供互链。
- [x] 前端格式检查、类型检查、生产构建和浏览器渲染检查通过。

## 9. 实施与验收记录

- 实现：`vue-i18n` 集中消息资源，支持 `en-US` 与 `zh-CN`。
- 持久化：使用 `localStorage` 键 `codetrove.locale`，缺省回退为英文。
- 覆盖：全局布局、仓库、Pull Request 列表与详情、Actions、Settings、Toast、空状态及无障碍标签。
- 文档：英文 `README.md` 与中文 `README.zh-CN.md` 已互链并保持命令与配置一致。
- 自动化检查：`npm run format:check`、`npm run typecheck`、`npm run build` 均通过。
- 浏览器检查：默认英文、中文切换、刷新持久化、路由保持与页面状态保持均通过；所有现有路由在中文下无运行时错误。
- 技术标识：分支、commit hash、测试键、错误码、路径和代码按规范保持原文。
